# 護眼同樂會｜長者團體視力互動遊戲

🔗 線上版：https://mattsue1003.github.io/eye-games-for-seniors/

給社區據點、樂齡課程、長照機構使用的**團體視力互動網頁遊戲**。
老師把畫面投影出來，阿公阿嬤一起看、一起喊答案；畫面下方只有「揭曉答案」「下一題」兩個大按鈕，方便老師帶領。

> 全部玩法都設計成**團體帶領**：長輩不需要碰螢幕，用喊的、用手比就能參與。
> 單一 `index.html`，不需安裝（字型由 Google Fonts 載入，離線時自動改用系統字型），手機、平板、電腦皆可。視覺風格：白底、粗黑邊框、亮黃按鈕的美式線條風。
> 本遊戲僅為互動體驗與衛教，**不是正式視力檢查**。看不清楚、直線變彎、閃光或黑影變多，請到眼科檢查。

## 三大分類、12 種玩法

### 視力・護眼（眼睛本身看得清不清楚、常見眼疾與日常護眼）

| 玩法 | 內容 | 衛教重點 |
|---|---|---|
| 缺口比一比 | C 字環或 E 字，缺口朝哪邊大家用手比出來；九級大小可調 | 視力體驗、兩眼差異覺察（非正式檢查） |
| 方格表檢查 | 阿姆斯勒方格表六步驟教學；「看圖辨異常」分辨彎曲、黑影、缺一塊、模糊 | 黃斑部病變自我檢查 |
| 看出去的樣子 | 同一座公園，白內障／青光眼／黃斑部病變／糖尿病視網膜病變看出去會變怎樣 | 認識四大常見眼疾與警訊 |
| 視錯覺 | 繆勒—萊爾、艾賓浩斯、龐佐、咖啡牆、赫曼方格、同色不同感、直橫線，揭曉時出現輔助線證明真相 | 眼見不一定為憑，看不清楚要再確認 |
| 護眼問答 | 20 題是非＋選擇，大家比 ○✕ 或手指 1、2、3 | 護眼好習慣、就醫時機 |
| 眼球操 | 跟著球做：掌心熱敷→上下→左右→轉圈→遠近對焦→眨眼 | 眼睛放鬆運動（痛、暈就停） |

### 視知覺（眼睛看到之後，大腦怎麼分辨、比較、追蹤）

| 玩法 | 內容 | 訓練重點 |
|---|---|---|
| 找不一樣的字 | 相似字裡找出不一樣的那一格（大／犬、未／末…），每格有大號碼可直接喊 | 視知覺、識能 |
| 說出顏色 | 字寫「紅」卻是藍色，大聲說出「字的顏色」；1～6 個字、可自動換題 | 眼睛＋認知雙重訓練（Stroop） |
| 數一數 | 很多形狀裡數出指定的「紅色圓形」有幾個 | 視覺搜尋、專注力 |
| 杯子追蹤 | 球放進杯子後洗牌，眼睛盯緊，最後喊出球在幾號位置；3～5 個杯子、三種速度 | 視覺追視 |

### 視覺反應（目標閃一下在哪？全班一起找、一起喊）

| 玩法 | 內容 | 訓練重點 |
|---|---|---|
| 眼明手快 | 黃色星星在編號格裡閃一下（1.5／1／0.5 秒），大家喊出幾號格；可連閃 2～3 個記順序 | 視覺反應、周邊視野、短期記憶 |
| 數字搜尋 | 打亂的數字表（3×3～5×5），全班從 1 依序找、大聲唸，老師點選確認並計時（舒爾特方格） | 視覺搜尋、專注力 |

## 老師帶領功能

- **揭曉答案／下一題／上一題** 大按鈕；鍵盤 `空白鍵` 揭曉→下一題，`←` `→` 切題，`Esc` 回首頁，`F` 全螢幕，`T` 計分板。
- **🏆 分桌計分**：2～6 桌，桌名可改，＋／－ 計分、一鍵歸零。
- **⏱ 倒數**：按一下 10 秒、再按 20 秒、再按 30 秒，最後 3 秒有提示音。
- **📋 老師小抄**：每個玩法都有帶領步驟、建議說法與衛教重點。
- 每個玩法上方有難度／數量／速度等選項，設定會記在瀏覽器裡。

建議流程（約 60 分鐘）：眼球操暖身 → 找不一樣的字 → 說出顏色 → 數一數 → 眼明手快 → 杯子追蹤 → 數字搜尋 → 視錯覺 → 看出去的樣子 → 方格表檢查 → 護眼問答 → 缺口比一比。每個玩法 5～10 分鐘，中間讓大家閉眼休息。所有玩法都是全班一起看、一起喊或用手比，長輩不需要碰螢幕，老師一個人操作即可。

## 使用方式

- **線上**：開啟 GitHub Pages 網址（見本頁右側 About 或下方 Deployment）。
- **離線**：下載 `index.html`，直接用瀏覽器打開即可。
- **本機預覽**：`python3 -m http.server 8000` 後開啟 http://localhost:8000

## 自行修改題庫

所有題目都在 `index.html` 的 `<script>` 開頭「資料」區塊：

- `ODD_EASY` / `ODD_HARD`：相似字組
- `COLORS`：顏色字
- `AMSLER_TYPES`、`DISEASES`：方格表異常與眼疾說明
- `QUIZ`：問答題（`t:'ox'` 是非題、`t:'mc'` 選擇題）
- `ILLUSIONS`：視錯覺題目（SVG 圖、選項、說明）
- `EX_STEPS`：眼球操步驟與次數
- `ICONS`：線條圖示（SVG path）
